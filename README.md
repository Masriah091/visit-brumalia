# BRUMALIA — Where Winter Keeps Its Capital

A travel poster for a place that isn't there: **BRUMALIA**, a frozen capital
of glowing ice palaces under the aurora, reached by a red 1930s steam train
crossing the snow. Drawn entirely in code (Python + Pillow) — the poster is
generated by `main.py`, which writes `/output/entry.png` (1024×1024, ≤1 MiB).

## How to run

```bash
python3 main.py
# writes /output/entry.png
```

The only text in the poster is the place name, **BRUMALIA**, set in
Playfair Display 900. The landmark is a single glowing ice palace beneath
an aurora; the composition leads the eye from the name, to the palace,
to the train and the horizon.
